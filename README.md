# Прогнозирование покупки по данным пользовательской сессии

Цель — построить модель бинарной классификации, которая по данным пользовательской сессии прогнозирует, завершится ли она покупкой.

## Данные

Использован датасет **Online Shoppers Purchasing Intention Dataset**.

Он содержит 12 330 пользовательских сессий, 17 признаков и целевую переменную `Revenue`:

- `True` — сессия завершилась покупкой
- `False` — покупка не совершена

Датасет выбран, потому что:

- подходит для задачи бинарной классификации
- содержит числовые и категориальные признаки
- имеет дисбаланс классов
- позволяет сравнить разные способы предобработки и несколько моделей

Исходный источник:

[Online Shoppers Purchasing Intention Dataset на Kaggle](https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset)

## Гипотезы о данных

До анализа данных были сформулированы шесть гипотез:

1. В сессиях с покупкой медианное количество просмотренных товарных страниц выше, чем в сессиях без покупки
2. В сессиях с покупкой медианная длительность просмотра товарных страниц выше, чем в сессиях без покупки
3. В сессиях с покупкой медианный показатель отказов ниже, чем в сессиях без покупки
4. Доля сессий с посещением административных страниц выше среди сессий с покупкой
5. Доля покупок среди вернувшихся посетителей выше, чем среди новых
6. Доля покупок увеличивается с ростом значения `SpecialDay`

## Гипотезы о моделировании

Перед модельными экспериментами были сформулированы ещё три гипотезы:

1. Логарифмическое преобразование правосторонне асимметричных признаков улучшит качество логистической регрессии
2. Балансировка классов повысит recall покупок, но может снизить precision
3. Случайный лес покажет более высокое качество, чем логистическая регрессия и одиночное дерево решений

## Что сделано

В ноутбуке выполнены:

- первичный анализ и EDA
- проверка пропусков, дубликатов и экстремальных значений
- анализ распределений и корреляций
- статистическая проверка гипотез
- разделение данных на обучающую и тестовую выборки
- предобработка числовых и категориальных признаков
- сравнение логистической регрессии, дерева решений и случайного леса
- пятифолдовая стратифицированная кросс-валидация
- подбор гиперпараметров через `RandomizedSearchCV`
- отбор признаков через `SelectFromModel`
- проверка чувствительности модели к признаку `PageValues`
- финальная оценка на отложенной тестовой выборке

| № | Результат | Краткий вывод |

## Итоговая модель

Лучший результат показал настроенный случайный лес со всеми признаками.

Результаты на тестовой выборке:

| Метрика | Значение |
|---|---:|
| Accuracy | 0,905 |
| Precision | 0,732 |
| Recall | 0,623 |
| F1 | 0,673 |
| ROC-AUC | 0,933 |
| PR-AUC | 0,754 |

Результаты на тестовой выборке практически совпали с результатами кросс-валидации.

## Ограничение

Наиболее важным признаком модели стал `PageValues`. После его исключения валидационный PR-AUC снизился с 0,754 до 0,379.

Перед практическим использованием модели необходимо проверить, доступен ли этот признак в момент прогноза и не использует ли он информацию, полученную после завершения покупки.
